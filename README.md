# App Hub (self-hosted PWA)
1. Upload this folder to any HTTPS host (GitHub Pages, Netlify, Cloudflare Pages).
2. Open it on your phone and use "Add to Home Screen" (iPhone: Share menu; Android: Chrome menu > Install).
3. For a topic-only hub, open `yoursite/#work` (or any topic) and add that to the home screen too.
Your apps are saved on the phone. Use Backup to copy them between devices.
